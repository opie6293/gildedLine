# Gilded Line — Build a Legacy

A browser dynasty and wealth sim: start anywhere from 1850 to today, build a fortune, raise heirs, race horses, and carry your house through two centuries of history.

## Play
Open `index.html` in any browser, or play the hosted version via GitHub Pages.

## Install on iPhone
1. Open the GitHub Pages link in **Safari**.
2. Share → **Add to Home Screen**.

It runs full-screen and works offline. Saves live on the device; use ⚙ → Export / Import to move a game between devices.

## Files
- `index.html` — the whole game
- `manifest.webmanifest`, `icons/` — home-screen app
- `sw.js` — offline support
